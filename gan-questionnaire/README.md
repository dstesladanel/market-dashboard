# שאלון תפקודי · גני חינוך מיוחד (חריש)

כלי עבודה פנימי. אין בו שמות ילדים, תעודות זהות או תאריכי לידה: רק שם גן ומספר ילד פנימי.
הוא לא מאבחן, לא קובע זכאות ולא מחליף ועדת זכאות ואפיון או שאלון ראמ״ה.

אתר סטטי (HTML + JS בלי שלב build) על Firebase: Authentication + Firestore + Hosting.

## מה יש בו

| תפקיד | מה רואה | מה יכולה להוריד (Excel, עדכני ברגע הלחיצה) |
|---|---|---|
| **גננת** | דשבורד הגן (רדאר, ממוצע לתחום, התפלגות, מגמה, ילדים מסומנים), דשבורד לכל ילד, פרופיל מלא עם התשובות והטקסט החופשי | דוח ילד (כולל גיליון תשובות), דוח גן (כולל "תשובות מלאות") |
| **סייעת** | רק רשימת ילדים ומילוי של היגדים שסומנו עבורה (טיפול עצמי, חצר, מעברים). לא מסיימת מילוי | – |
| **מנהלת מערך** | תמונת מערך (מטריצת גנים×תחומים, השוואת גנים, מגמה, ילדים מסומנים), דשבורד לכל גן, דשבורד לכל ילד לפי מספר פנימי, ופרופיל מלא עם התשובות הפרטניות והטקסט החופשי (קריאה בלבד) | דוח מערך, דוח גן, דוח ילד, כולם כולל גיליון תשובות מלאות |
| **מנהלת: עריכה** | עריכת השאלון (תחומים, היגדים, עוגנים ל-1 ול-5, סוג תשובה, דגל בטיחות, סימון לסייעת), גנים ומשתמשות | – |

* סולם 1–5 (5 = יותר עצמאות והשתתפות), 0 = לא רלוונטי / לא נצפה ולא נכנס לממוצע. כן/לא וטקסט לא נכנסים לממוצע. אין ציון כולל.
* **גרסאות טופס:** כל פרסום יוצר גרסה חדשה ואינו משנה גרסאות קודמות, כדי שמילוי ישן יישאר קריא והשוואה לילד עצמו תישאר תקפה.
* **פרטיות:** הנתונים מזוהים רק במספר פנימי. צוות הגן ומנהלת המערך קוראים את תיק הילד (`responses`); רק צוות הגן ממלא, מעדכן ומוחק. כללי האבטחה נאכפים בשרת, לא רק בממשק.

## הקמה (פעם אחת)

1. ב-[Firebase Console](https://console.firebase.google.com) צרו פרויקט.
2. **Authentication → Sign-in method**: הפעילו Email/Password.
3. **Firestore Database**: צרו מסד נתונים (Production mode).
4. **Project settings → Your apps → Web app**: העתיקו את ה-config ל-`js/firebase-config.js`.
5. התקינו `npm i -g firebase-tools`, ואז מתוך התיקייה הזאת:
   ```
   firebase login
   firebase use --add          # בחרו את הפרויקט
   firebase deploy --only firestore:rules,hosting
   ```
6. פתחו את כתובת האתר ולחצו **"הקמה ראשונה של המערכת"**. החשבון הראשון הופך למנהלת המערך ומקבל את תבנית הפיילוט (גרסה 1). אחרי ההקמה האפשרות נסגרת בכללי האבטחה.
7. כמנהלת: **גנים ומשתמשות** → הוסיפו גנים ואז משתמשות (גננת/סייעת) ושייכו אותן לגנים. המערכת שולחת קישור להגדרת סיסמה.

## בדיקות

```
node test/scoring.test.mjs      # ממוצעים, 0 לא נספר, דגלים, סייעת, השוואה
node test/reports.test.mjs      # בניית הדוחות והנתונים לדשבורדים
```
```
npm i -D firebase-tools @firebase/rules-unit-testing firebase
npx firebase emulators:exec --only firestore --project demo-gan "node test/rules.test.mjs"   # 55 בדיקות כללי אבטחה
```
`test/ui-smoke.mjs` מריץ את כל הזרימה בדפדפן מול Firebase מדומה בזיכרון (`test/fake-firebase.mjs`). הוא בודק ממשק ודוחות. כללי האבטחה נבדקים בנפרד ב-`test/rules.test.mjs` מול Firebase Emulator.

## מגבלות ידועות

* הגבלת הסייעת להיגדים מסומנים נאכפת בממשק בלבד (כללי Firestore לא בודקים מפתחות בתוך `answers`).
* ספריית ה-Excel (SheetJS) נטענת מ-cdnjs בעת הורדת דוח ראשונה.
* חשבון Auth נשאר קיים כשמסירים הרשאה; בלי פרופיל הוא לא רואה כלום.
